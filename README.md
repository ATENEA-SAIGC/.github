# ATENEA-SAIGC/.github

Repositorio de configuracion de la organizacion. El archivo
[`profile/README.md`](profile/README.md) es la pagina de inicio publica que
se muestra en https://github.com/ATENEA-SAIGC.

**Al publicar un algoritmo nuevo**, agregue su fila en la tabla de la
convocatoria correspondiente dentro de `profile/README.md` y actualice el
contador del badge "Algoritmos publicados".
